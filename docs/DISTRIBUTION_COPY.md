## Show HN / open-source launch draft

Show HN: Evidence-First Security Questionnaire Response Kit

I built a small local-first toolkit for teams that receive customer security questionnaires.

It includes a deterministic Python CSV triage script, evidence-register template, human QA checklist, audit receipt, and a landing page. It does not call an API, upload files, submit questionnaires, or generate unsupported security claims.

The goal is simple: turn a messy questionnaire into a reviewable work queue without pretending automation can replace a security or compliance owner.

Free download: https://strawberrybrowser.com/files/sRH4d1Q7PsW4Rq4K
Product page: https://strawberrybrowser.com/files/S6Eq75a7Aq3oq_IW

I would value feedback on the triage categories, missing evidence types, and whether this local-first format is useful.

## Community post draft

I made a free local-first security questionnaire response kit for B2B teams. It includes a Python triage script, evidence register, citation workflow, human QA checklist, and audit receipt. No API key or upload required.

Download: https://strawberrybrowser.com/files/sRH4d1Q7PsW4Rq4K
