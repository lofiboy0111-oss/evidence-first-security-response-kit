## Hacker News — Show HN

Title:

Show HN: Evidence-First Security Questionnaire Response Kit — local triage for B2B security reviews

Body:

I built a small local-first workflow for a problem that gets surprisingly expensive as B2B companies start selling to larger customers: security questionnaires.

The kit takes a questionnaire CSV and adds deterministic categories, priority levels, risk flags, likely evidence needs, and a review-status field. It also includes an evidence register, QA checklist, answer-citation structure, and audit receipt template.

The script uses only Python's standard library. It does not upload files, call an AI provider, submit questionnaires, or claim that a company is compliant. The intent is to make the mechanical work more repeatable while keeping judgment and release decisions with a qualified human.
